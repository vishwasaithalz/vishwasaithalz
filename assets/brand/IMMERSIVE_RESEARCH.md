# VISHWAS.EXE | Physical Desktop and Internet Archive Research

Owner: Vishwas Aithal
Status: Original review branch, no production merge

## Design goal

Build a personal retro computer with believable physical materials, readable interactions and actual working browser programs. Preserve original game logic and the full museum dataset.

Reference projects are **design and interaction research only**. This branch does not copy their code, logos, photography, fonts or bundled media.

| :-- | :-- |

## Accessibility and safety

* All primary links to destinations on the project Pages website open new tabs with noopener and noreferrer.
* Same page fragment links remain local because they control the current app panel or archive section.
* Native GitHub.com README link behavior is outside the site's control.
* Keyboard shortcuts, game inputs and in page navigation are preserved.
* No automatically played audio, device access or new network requests.
* The layout respects reduced motion preference and narrow screens.
* Technical identifiers, internal file paths and repository names are preserved even when they contain ASCII hyphens.
* The user requested no long dash punctuation or spaced hyphens in visible public copy. The quality check enforces this for profile copy and public pages.
