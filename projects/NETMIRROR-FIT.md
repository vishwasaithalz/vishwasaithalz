# NetMirror.fit

**Creator:** Vishwas Aithal  
**Live site:** https://netmirror.fit  
**Project type:** Legal movie, television and anime discovery  
**Status:** Active project, public repository preparation in progress (November 2026)

NetMirror helps people discover films, series and anime through curated collections, regional catalog browsing, streaming-provider references, official trailers, soundtrack embeds, quotes and browser-local watchlists.

It is a **discovery service**. It does not host or distribute copyrighted movies or streams.

## Stack and architecture

- Next.js 16, React 19, TypeScript
- Vercel preview and currently deployed project under the YYYH workspace
- Target production runtime: Cloudflare Workers
- Google AI Studio and local PowerShell workflows for design and development
- Server-side third-party API integration with secrets stored outside public code

## Public source migration

The owner-shared Google Drive source was recovered for a dedicated public GitHub repository named **`netmirror-fit`**. The recovered archive is a dated source snapshot, not a guaranteed byte-for-byte reproduction of the newest production deployment. Sensitive local configuration and build artifacts were excluded during packaging.

A standalone repository must be created before source can be pushed. Do not confuse this project overview inside the profile repository with the source repository itself.

## Principles

- Accurate metadata, clear provider attribution and lawful watch options
- Fast, accessible browsing across devices
- Distinctive interface design without hiding content
- No fabricated ratings, news, or streaming availability
- No credentials, private watchlists or production secrets in public code
